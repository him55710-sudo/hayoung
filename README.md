# 500일의 방

임현수와 정하영의 500일을 위한 풀스크린 1인칭 3D 웹 방탈출 게임 프로젝트입니다.

부제: **임현수와 정하영의 기억 방탈출** — "우리의 추억을 기억해야만 이 방에서 나갈 수 있다."

React + TypeScript + Vite + Three.js 순수 웹 빌드로 동작하며, Unreal Engine과 MCP 없이 실행됩니다.

## 빠른 시작

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 열면 게임을 볼 수 있습니다.

## 현재 구현

### 시작 화면
- 3개 테마 포스터 선택 (Theme 01 연애 일대기만 플레이 가능, 02/03은 잠금)
- Theme 01 선택 시: `임현수와의 500일을 함께하실 준비가 되셨나요?`
- 데스크톱: 커서가 가까워지면 `네` 버튼이 피하다가 6초 뒤 클릭 가능 (도망갈 때 장난스러운 효과음)
- 모바일: 터치하면 버튼이 미끄러지듯 이동
- 저장된 진행이 있으면 `이어하기` 버튼 표시

### Room 1 — 실제 추억 퍼즐 체인 (8문제, 선형 의존)
0. **VITA500 편지** — 생일 선물 테이블의 봉인된 편지, 단어 자물쇠 (한글 `비타500` 허용)
1. **액자 4개 시간순 정렬** — 잣절공원 고백 → 현수 생일 → 필리핀 → 100일 홍대, 색상 입력 노랑→초록→파랑→빨강
2. **바이올린 키링 장착** — 유리 진열장 속 바이올린 인형의 빈 고리에 키링 사용 (다른 대상은 실패)
3. **인생의 회전목마** — 바이올린 인형이 연주하는 곡의 제목 맞히기 (임시 자체 신시사이저 왈츠, 실제 음원은 TODO_USER_MEMORY)
4. **놀이공원 그림** — 인벤토리의 회전목마 모형을 그림의 빈자리에 삽입 → 구로평상 단서
5. **구로평상과 9번 칸** — 3×3 바닥 타일에서 9번 칸 (연결 근거는 TODO_USER_MEMORY)
6. **소고기 부위 맞히기** — 소 그림에 조각 배치 후 `살치살` 입력
7. **두 스테이크 중 선택** — 홍대 알페로 스테이크(오답, 촛불 꺼짐 연출) vs **현수의 스테이크**(정답) → Room 2 문 개방

### 스토리와 연출
- 오프닝: 현수의 음성 오버레이 ("우리의 500일을 제대로 기억하고 있어?")
- 스테이션 상호작용: 방 안 11개 지점(안내 책상, 잣절공원 벤치, 선물 테이블, 액자 벽, 진열장, 오르골, 그림, 바닥 타일, 소고기 벽, 스테이크 테이블, 출구 문)에 가까이 가면 레티클/바닥 링/조사 버튼이 반응
- 정답 시 3D 반응: 액자 순차 점등, 인형 연주 모션, 회전목마 회전/이동, 9번 타일 하강, 살치살 마커 발광, 촛불 밝아짐, 출구 문 힌지 개방 + 문틈 황금빛
- 사진 슬롯: 실제 사진 제공 전까지 TODO_USER_MEMORY 표시 (임의 생성 금지)
- Room 2~4: 환경과 진입문만 유지, `다음 기억을 준비 중입니다` 안내판
- Room 5 + 엔딩: 하늘문, 구름길, 마지막 편지, 6개 교체형 사진 타임라인, 힌트 사용 기록 표시

### 시스템
- 힌트 계약서: 3회 제한, 단계별(위치→연결→정답 직전) 안내 + 벌칙 도장 (바나나우유/설빙/방탈출 데이트), 엔딩까지 기록 유지
- 저장: localStorage 자동 저장, 새로고침 후 이어하기, `처음부터` 버튼으로 초기화
- 사운드: 퍼즐별 Web Audio 효과음(봉인 해제, 색 버튼, 키링, 오르골, 타일, 문 볼트 등) + 방별 절차형 앰비언스
- 그래픽 품질: 시네마틱/균형/부드럽게 순환 (렌더 해상도, 블룸, 그림자, 먼지 조절)
- 1인칭 체감: 하영이 시점의 손, 손전등, 하트 열쇠, 머리카락, 치마 실루엣, H/Y 이름 참 리그
- 모바일: 좌측 이동 패드, 우측 시점 패드, 조사/힌트 버튼, 압축 HUD

## 검증

```bash
npm run build
npm run verify:game
npm audit --omit=dev
```

검증 단계가 멈출 때만 디버그 로그를 남기려면:

```bash
$env:DEBUG_GAME_VERIFY="1"; npm run verify:game
```

배포 URL을 검증할 때:

```bash
$env:GAME_URL="https://hyunsu-hayoung-400.vercel.app"; npm run verify:game
```

## 배포

```bash
npm run build
npx vercel deploy
```

프로덕션 배포가 필요할 때만:

```bash
npx vercel deploy --prod
```
